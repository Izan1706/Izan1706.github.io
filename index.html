HomeLab & Infraestructura Local

Servidor personal autoalojado diseñado para aprender, experimentar y tener soberanía total sobre mis datos. Corre 24/7 sobre hardware reutilizado con Ubuntu Server 24.04 LTS.

Objetivo: Eliminar dependencias de servicios cloud, practicar administración en producción real y aplicar seguridad a diferentes niveles.

Tecnologías Utilizadas

Ubuntu Server 24.04 Docker & Compose PiHole Immich Netdata Lynis NMAP

Características Clave

  • DNS de red doméstica con bloqueo de publicidad y dominios maliciosos (PiHole)
  • Galería fotográfica privada autoalojada con IA local (Immich)
  • Monitorización en tiempo real con alertas de hardware (Netdata)
  • Auditorías de seguridad periódicas con Lynis y NMAP
  • Acceso remoto exclusivamente mediante SSH y VPN

IA Generativa en Local

Despliegue completo de un ecosistema de IA generativa sobre Linux y Docker, operando al 100% dentro de la red local. Ningún dato sale a internet. Soporta múltiples usuarios simultáneos y capacidades RAG para leer y procesar archivos del cliente.

Objetivo: Garantizar privacidad absoluta de los datos mientras se aumenta la productividad mediante modelos LLM de última generación.

Tecnologías Utilizadas

Linux Docker Ollama Open WebUI Mistral / Llama ComfyUI Flux.1

Componentes Clave

  • Motor de inferencia Ollama con aceleración GPU (RTX 4060 Ti 16GB)
  • Interfaz multiusuario con Open WebUI vía contenedor Docker
  • Capacidad RAG: aprende de archivos subidos por el usuario
  • Generación de imágenes con ComfyUI y modelo Flux.1 (GGUF cuantizado)
  • Privacidad total: ningún dato abandona la red local
