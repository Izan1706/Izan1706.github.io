Executive summary

Vision

Novacreux was created to bridge the gap between cutting-edge AI and robust security and data sovereignty. The premise is simple: a company or professional does not need to hand over their data to third parties to benefit from generative AI, automation or advanced monitoring — they can have everything on their own network. We believe that a secret leaving a secure place can create a security breach, which is why secrets never leave home.

Technical objective

Design, deploy and document the same AI and automation ecosystem across very different hardware tiers — from a low-power Raspberry Pi to a NVIDIA Spark de nivel profesional — para entender qué plataforma conviene a cada caso de real-world use case: cost, performance, energy consumption and scalability. This project also demonstrates that, as currently built, it can be easily scaled.

Ecosystem architecture

The project is divided into five independent blocks that share the same philosophy (local-first, with no external dependencies) but address different needs: core infrastructure, desktop AI, low-power embedded AI and professional-grade AI.

Block 1 · Core infrastructure

Homelab & Containerization

Behind any local AI service, infrastructure is needed to support it. A reused PC (Dell OptiPlex, Intel i7-4790, 16GB RAM, 436GB SSD) runs Ubuntu Server without a graphical interface, with each service isolated in its own Docker container: if one fails, the rest keeps running.

Block 2 · Desktop AI

Local Generative AI (PC)

The goal is to demonstrate that, with consumer hardware, it is possible to have professional-grade AI workflows with minimal latency and full control over the models — without any data leaving the local network. The stack runs on Ollama as the inference engine and Open WebUI as the interface, all in Docker containers.

Block 3 · Low-power Edge AI

Raspberry Pi 5 + AI HAT+2 — Video Analyzer

An 8GB Raspberry Pi 5 with the AI HAT+2 module (Hailo-8 NPU, 26 TOPS) runs a pipeline in Python with OpenCV and the Hailo API capable of describing video content: in a real-world environment this translates into detecting workplace hazards, smoke or objects without human intervention, and automatically triggering protocols or notifications.

  • BoardRaspberry Pi 5 — 8GB RAM
  • AcceleratorAI HAT+2 (NPU Hailo-8, 26 TOPS)
  • Average power consumption5–12 W
  • AI performance3–5 tokens/s (modelos de 3B)
  • Software stackPython venv · OpenCV · hailo-python-api · Ollama
  • Use caseComputer vision / Edge IoT

Lessons learned and next steps

What worked

  • Segmenting each service in Docker prevents a failure from bringing down the rest of the homelab.
  • Comparing 5 real platforms teaches more than any specification table: each one has a clear use case.
  • Using the project itself (the n8n agent) in production on this portfolio, not just as a demo.
  • Measure actual power consumption and cost before recommending a platform, not just performance.

Next steps

  • Live Raspberry video analyzer (real-time camera, not pre-recorded video).
  • Migrate the VPN from Tailscale to 100% self-hosted WireGuard.
  • Replace Fail2ban with CrowdSec, with shared intelligence between nodes.
  • Raspberry chatbot accessible via WhatsApp/Telegram, orchestrated with n8n.
  • Set up a NAS with real redundancy for the homelab.

VPN · Tailscale

WireGuard-based VPN solution that allows connecting to the homelab network from virtually any device (Ubuntu Server, Windows, Android) without exposing ports or data to the internet. Configuration is minimal: install the client and link an account.

Key Features

  • Administration dashboard with all connected devices and their IPs
  • Granular access control by user and device
  • Magic DNS: access services by name instead of IP
  • Funnels to expose a local service in a controlled way
  • Logs enabled for auditing
Tailscale Wireguard Zero Trust

Pi-Hole

Private DNS server to filter ads and malicious domains across the entire home network, and to assign easy-to-remember names to local services instead of IPs.

Key Features

  • Network-level ad and tracking blocking, without installing anything on each device
  • Local name resolution (internal DNS)
  • Real-time statistics on blocked queries
  • Runs on port 53, containerized with Docker
Pi-Hole DNS Docker

Immich Gallery

Open-source self-hosted platform for managing photos and videos over the network, a free alternative to Google Photos, with automatic synchronization from mobile.

Key Features

  • Gallery synchronization from mobile or other devices
  • Local Machine Learning for recognition and search
  • Deployed with Docker Compose: server, Postgres, Redis and ML module
  • Clients available via web, Apple and Android
  • Reduces device storage usage and avoids paid services
Immich Docker Compose PostgreSQL Redis

Fail2ban

Brute-force intrusion prevention system. It monitors system logs and, when it detects too many failed login attempts from the same IP, automatically creates a firewall rule that bans it for a configurable period.

Key Features

  • Specific SSH jail enabled
  • Configurable parameters: bantime, findtime and maxretry
  • Tested in real conditions: 5 failed attempts from a mobile device triggered the expected ban
  • Planned replacement with CrowdSec, with shared intelligence between nodes
Fail2ban SSH Hardening

Uptime Kuma

Self-hosted monitoring tool with a modern visual interface. It monitors services, TCP ports, pings and Docker containers, and sends alerts in case of an incident.

Key Features

  • Monitors configurable by TCP port, ping or DNS
  • Historical incident log
  • Alerts when services go down
  • Deployed in Docker, port 3001
Uptime Kuma Monitoring Docker

Netdata

Real-time infrastructure monitoring with full server visibility: CPU, memory, disks, network and services. It complements Uptime Kuma with highly detailed hardware-level performance data.

Key Features

  • Fast Docker deployment with --pid=host and --network=host
  • Read-only volumes over /proc and /sys for maximum security
  • Visual identification of anomalies and bottlenecks
  • Per-second metrics, without complex configuration
Netdata Observability Docker

n8n

Node-based workflow automation platform, fair-code and self-hostable — free alternative to Zapier, with no execution limit (only limited by the hardware itself). It is the orchestrator of this portfolio's AI agent.

Key Features

  • Orchestrates the AI agent with RAG that handles this website's chat
  • API integrations with multiple services
  • Management, startup and notification of Docker containers
  • Foundation for automating backups and repetitive processes
n8n Automation RAG Low-code
