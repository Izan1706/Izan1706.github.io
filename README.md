## 🛠️ Stack Técnico del Portfolio

Este portfolio ha sido construido desde cero utilizando un stack nativo y ligero, demostrando que no se necesitan frameworks pesados para construir una plataforma técnica de alto rendimiento:

* **HTML5:** Estructura semántica y diseño web responsive.
* **CSS3:** Sistema de diseño propio basado en Custom Properties (Variables), glassmorphism y modo claro/oscuro.
* **JavaScript (Vanilla):** Interactividad completa, manipulación del DOM, modales y lógica sin librerías externas.
* **SVG Nativo:** Diagramas de topología de red y arquitecturas de sistemas dibujados directamente en código.
* **Node.js:** Backend ligero para el ecosistema Izanagi (Dashboard de métricas y Kanban).

## 📂 Estructura del Portfolio

El sitio web se divide en las siguientes áreas clave, cada una documentando un aspecto de mi perfil técnico:

1. **Home (`index.html`):** Resumen ejecutivo, experiencia, stack tecnológico y proyectos destacados.
2. **Homelab (`homelab.html`):** Documentación de la infraestructura local.
   * *Virtualización:* Proxmox
   * *Contenerización:* Docker
   * *Monitorización:* Netdata, Uptime Kuma
   * *DNS:* PiHole
   * *Seguridad:* Fail2ban, Lynis
3. **Novacreux (`novacreux.html`):** Proyecto Final de Grado (TFG - 121 páginas). Ecosistema modular de IA local y Edge AI desplegado sobre 5 plataformas de hardware distintas (NVIDIA Spark, Jetson Orin Nano, Raspberry Pi, etc.).
4. **Izanagi (`izanagi.html`):** Desarrollo propio. Dashboard de acceso centralizado a servicios y Kanban board con Drag & Drop nativo y persistencia en `localStorage`.
5. **IA Local (`ia_local.html`):** Despliegue de IA generativa (Ollama, Open WebUI, ComfyUI, Flux.1) 100% privada y local.
